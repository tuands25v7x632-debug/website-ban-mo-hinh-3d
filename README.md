# Website quản lý bán mô hình in 3D

Dự án nhóm môn CT275 – Công nghệ Web, học kỳ 1 năm học 2026–2027.

Mã nguồn sẽ được phát triển trên các nhánh riêng và xem xét qua Pull Request. Công nghệ: PHP 8.3+, PDO, MySQL/MariaDB, Composer PSR-4, MVC và Bootstrap 5.

Xem nhánh `feature/customer-setup` để biết mã nguồn khởi tạo Bước 1.
